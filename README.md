# 课间隙 · 学习任务板

一个使用 HTML、CSS 和原生 JavaScript 完成的轻量个人学习任务板。项目不接入真实用户数据，不需要密钥或后端服务，所有任务只保存在当前浏览器的 localStorage 中。

## 功能

- 添加课程任务，记录预计用时和重点状态
- 一键标记完成或恢复任务
- 按“全部 / 进行中 / 已完成”筛选
- 自动计算今日完成进度
- 删除任务、空状态和操作反馈
- 响应式布局，支持键盘操作

## 本地运行

直接打开 dist/index.html，或在项目根目录启动任意静态文件服务器并访问 dist 目录。

## 项目结构

```text
dist/
├── index.html
├── styles.css
└── app.js
```

## 隐私说明

本项目不收集或上传数据。浏览器本地保存的任务可通过清除站点数据移除。
